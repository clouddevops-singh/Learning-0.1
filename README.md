# DevOps Mastery — Zero to Production

A modern, high-converting, and beautiful landing page for the **DevOps Mastery** course. Built from scratch with premium visuals, dark mode aesthetics, interactive components, and smooth animations.

## 🚀 Features

- **Premium Modern Design**: Vibrant color palette, custom gradients, noise texture backdrop, and futuristic glassmorphic UI.
- **Interactive Syllabus/Curriculum**: Browse core learning tracks covering everything from Linux & Git to AWS, Kubernetes, Terraform, and AI-Powered Pipelines.
- **Fully Responsive**: Optimized for all devices—mobile, tablet, and desktop.
- **Micro-animations**: Smooth hover transitions, scrolling reveals, animated counters, and custom visual cues.
- **SEO Optimized**: Formatted with modern tags, semantic elements, and structured headings.

## 🛠️ Getting Started / Local Development

Since this project consists of pure static files (HTML, inline CSS, and JavaScript), you can view it directly:

1. Clone or download this repository.
2. Open `docs/index.html` in any web browser.
3. (Optional) Run a simple local server to see updates and mock features:
   ```bash
   # Using Python 3
   python3 -m http.server 8000
   
   # Or using Node.js (npx)
   npx serve docs
   ```
